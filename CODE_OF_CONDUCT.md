# Code of conduct

## Our standard

This project is a small research repository. Participation requires:

- treating other people with respect
- criticizing code and ideas, not people
- accepting technical review and correction
- keeping discussions on topic and free of spam
- respecting privacy: do not publish credentials, private records or another
  person's workspace contents

Unacceptable behavior includes harassment, discrimination, threats, doxxing,
deliberate disruption and publishing private information without consent.

## Scope

This applies to issues, pull requests, discussions, security reports and any
other project space.

## Enforcement

Maintainers may edit, lock or remove contributions that violate this policy and
may block repeat offenders. Enforcement decisions are made in private.

Report conduct problems to the maintainer through GitHub. For security
vulnerabilities, use [`SECURITY.md`](SECURITY.md) instead.
